# Portfolio Image Evaluation Rubric

Use this rubric for the 54 generated portfolio images:

1. Text safety
   Pass only if there are no readable words, letters, numbers, labels, captions, badges, pills, watermarks, logos, company names, or client names. Abstract marks are acceptable only when they are not text-like.

2. Project specificity
   The image should visually connect to the project or article topic. It should not read as generic AI, generic dashboard, generic abstract data art, or an unrelated scene.

3. Role fit
   Project cover images should establish project identity. Project evidence images should show implementation, process, provenance, or technical grounding. Article heroes should read as narrative editorial images for the article thesis.

4. Sibling distinction
   The two project images and the article image for the same repo must differ in visual device, camera distance, object family, and composition. Cohesion is allowed; near-duplicates are not.

5. Portfolio diversity
   Across the full set, images should vary in medium, palette, texture, lighting, camera treatment, metaphor, and mood. The set should not collapse into one repeated teal/glass/dashboard style.

6. Website usability
   The image must work as a 16:9 card/hero: safe margins, one dominant focal system, no important detail clipped, clean crop tolerance, and readable silhouette at thumbnail size.

7. Editorial polish
   The image should feel deliberate and high-quality: balanced composition, clean lighting, controlled contrast, no obvious AI artifacts, no confusing focal clutter, and no dull placeholder look.

## Scoring

Score each criterion from 1 to 5.

Pass threshold:
- Text safety must pass.
- Average score must be at least 4.0.
- No non-text criterion may score below 3.

Failing assets should be regenerated by changing only the relevant prompt direction, then re-evaluated against the same rubric.
